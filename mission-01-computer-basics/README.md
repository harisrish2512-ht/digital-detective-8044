### Task 1.1 — IPOS: typing and saving a document
| Stage | What happens in my example | Hardware / component |
|---|---|---|
| Input | Typing and the keyboard sends signals | Keyboard |
| Processing | CPU converts signals to characters & the editor holds the text in memory | CPU, RAM |
| Output | The text seen on the screen | Display |
| Storage | Clicking on save writes the file to permanent storage disk | SSD |

### Task 1.2 — Hardware and software
| Item | Hardware or software? | Software type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Enter text |
| Trackpad| Hardware | Not applicable | Move the pointer & Navigation - Cursor control |
| Display | Hardware | Not applicable | Shows output |
| RAM | Hardware | Not applicable | Store files temporarily |
| Windows/macOS | Software | Operating system | Manages hardware and resources |
| Terminal | Software | Application | CLI to interact with your Mac |
| AppStore | Software | Application | Browse and install apps |
| McAfee | Software | Utility (Antivirus/Disk Cleanup) | Protect or maintain the system |
