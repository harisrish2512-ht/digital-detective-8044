## 3. Commands / tools used
- `python3 --version` → [Python 3.13.14]: checks Python is installed
- `git --version` → [git version 2.55.0]: checks Git is installed
- `mkdir -p`: creates folders
- `touch`: creates empty files
- `git init`: starts a Git repository
- `git add .`: stages files for commit
- `git commit -m`: records a snapshot
- `git remote add origin`: links the local repo to GitHub
- `git push -u origin main`: uploads commits to GitHub
