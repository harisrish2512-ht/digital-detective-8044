### Task 4.2 - Comparison table:

| Point | Compiler | Interpreter |
|---|---|---|
| When translation/execution happens | Whole program translated before running | Executed line by line while running |
| Typical output | A machine-code/executable file | Direct results, no separate file |
| One Example | C (gcc) | Python |
| One Advantage | Usually faster at run time | Easy to test and debug quickly |

Compiler executed the code at once refering to bulk while interpreter executes code line-by-line. As of their execution process, Erros are easier to debug in interpreter than in compiler.
